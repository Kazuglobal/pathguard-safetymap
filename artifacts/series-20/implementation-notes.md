## Deviations
1. **rate の桁**: 遭遇: 画面（Three.js）は JSON の rate どうしを割り算して倍率を出すため、小数2桁で入れると参考が小さい回で倍率がずれる（正面衝突: 1.60÷0.03＝53倍、本当は46.0倍）。選択: EP21〜30 の rate は小数6桁で入れる（表示は2桁）。理由: 画面・原稿・キャプションの倍率を一致させるため。build_ep21-30.mjs が「JSON の数字で割った倍率＝原稿の倍率」を検査する。EP01〜20 は変えていない。
2. **0.1%未満の表示**: 遭遇: 追突 0.0348%・自転車24歳以下 0.0754% を 0.03%・0.08% と出すと、見る人の割り算が倍率と合わない。選択: 0.1%未満だけ小数3桁（0.035%・0.075%）。scene.js の `rateDigits` と原稿・キャプションで同じ規則。指示書の「小数第2位まで」からの逸脱。
3. **倍率の書き方**: 遭遇: 原稿を四捨五入（約12倍）、画面を切り捨て（×11.9）にすると同じ画面で食い違う。選択: 原稿・注記・キャプションも画面の `formatRatio` と同じ「小数1桁で切り捨て（100倍以上は整数）」。EP04 の「約21.3倍」と同じ書き方。
4. **テンプレートの修正（EP01〜20 の Three.js 版にも効く）**:
   - 参考・第3位・第2位の場面で、柱の数字が上部の見出し・UIにかかる回はカメラを後ろへ引く（`framed`）。収まる回は元の位置のまま
   - 第1位の着地後の全体の場面で注視点を 3.0→2.6 に下げ、柱の名前を下380pxより上に収める
   - フックの左右余白を 60→120px（長いフックは右120pxに入らず折り返す）
   - 見出し・倍率の大きな文字は、幅が840pxを超えるときだけ縮める（`fitWidth`）
   - 検査: `threejs/check_safe_area.mjs`（見えている文字が上220px・下380px・右120pxに入っていないかを測る）
5. **キャプションの出典**: 「出典：警察庁 交通事故統計オープンデータ（2023年）」と年を足した（動画の最後の表示と同じ）。
6. **ナレーションの締め**: 指示書どおり「誰に送るか」で終える。キャプションは既存の形なので「〇〇へ【保存＆シェア】」。
