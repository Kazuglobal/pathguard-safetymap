## Deviations
1. **rate の桁**: 遭遇: 画面（Three.js）は JSON の rate どうしを割り算して倍率を出すため、小数2桁で入れると参考が小さい回で倍率がずれる。選択: EP21〜30 の rate は小数6桁で入れる（表示は2桁）。理由: 画面・原稿・キャプションの倍率を一致させるため。build_ep21-30.mjs が「JSON の数字で割った倍率＝原稿の倍率」を検査する。EP01〜20 は変えていない。
2. **0.1%未満の表示**: 0.1%未満だけ小数3桁（0.036%・0.079%）。scene.js の `rateDigits` と原稿・キャプションで同じ規則。指示書の「小数第2位まで」からの逸脱。**HTML 版（template_winning_v3.html / batch_render.mjs）は小数2桁で出すので、EP21〜30 は Three.js 版で書き出すこと**（HTML 版だと参考が 0.04%・0.08% と出て原稿と合わない）。
3. **倍率の書き方**: 原稿・注記・キャプションも画面の `formatRatio` と同じ「小数1桁で切り捨て（100倍以上は整数）」。EP04 の「約21.3倍」と同じ書き方。
4. **レビュー（1回目）で変えた定義**（数字が確認時と変わった回）:
   - EP21: C01 → C31（衝突地点が「交差点内」の事故を除く。単路・その他は残す）。交差点の中の「前どうし」は右折車とのぶつかり等が混ざり、致死率0.28%と性質が違う（死亡94件中87件は単路）。「正面衝突」と呼ぶため除いた。46.0倍 → 67.7倍（2回目のレビューで、単路だけに絞っていた誤り〈69.0倍〉を文言どおりに直した）
   - EP22: 相手を四輪に限定（自転車にはねられた事故・相手不明を除く）。16.3倍 → 15.4倍
   - EP26: 相手を四輪に限定。25.0倍 → 24.9倍（切り捨て）
   - EP30: 相手を四輪に限定。7.1倍 → 6.5倍
   - EP27: 路線コード上4桁1500〜1999（主要地方道－市道）を市町村道へ。8.4倍 → 8.3倍
   - EP29: 「正面衝突」→「前どうしの衝突」。7割が交差点の中で、警察庁の「正面衝突」とは呼べない。交差点の中を除く版（C30）は第3位が条件を満たさないので C29 のまま、キャプションに定義を注記
5. **答えを伏せる**: 第1位を明かす前に出る caseTitle（HUD に0秒から）・badge・panelTitle・フック・最初の問いに、回ごとの `spoilers` の語を入れない（build が検査）。EP21「正面衝突の罠／HEAD-ON」、EP24「郊外の夜道の罠／RURAL NIGHT」を変えた。
6. **制限速度の回（EP25・EP30）**: EP25 は車とバイクにはねられた事故を数えるので、キャプションも「車に」と言わない（2回目のレビュー）。60km/h の道は 50km/h の道より低い（EP25 は画面にも出る。EP30 は死亡6件で並ばない）。原稿は「速くぶつかるほど命の危険は高まるといわれます」とぼかし、「速い道ほど危ない」とは言わない。EP25 のキャプションに「制限速度だけで危なさが決まるわけではなく、60km/hの道は50km/hの道より低い」、EP30 に「制限速度がもっと高い道は死亡事故が少なく比べていない」と書いた。EP30 の CTA は「車の速い道は避けて選ぶ」→「50km/hの道は特に慎重に」。
7. **テンプレートの修正（EP01〜20 の Three.js 版にも効く）**:
   - カメラ（`framed`）: 参考・第3位・第2位・全体の場面で、柱の数字が見出しにかからず（付け根が上から540px以下）、柱の名前が下380pxに入らない（付け根が上から1365px以上）ところまで引く。引くほど柱の間隔が詰まるので、注視点の高さも動かして引く量が最小の組を選ぶ。収まる回は元の位置のまま。barMax を超えて突き抜ける柱（EP01 の列車）は上の条件から外す
   - 柱の名前の箱を 240→180px、`word-break: auto-phrase`（文節で折り返す）。隣どうしの重なりを防ぐ
   - フックの左右余白を 60→120px。見出し・倍率の大きな文字は、幅が840pxを超えるときだけ縮める（`fitWidth`）
   - 検査: `threejs/check_safe_area.mjs`（見えている文字が上220px・下380px・右120pxに入っていないか、柱の数字が見出し類と、柱の名前どうしが重なっていないか）。EP01〜30 で主要な文字は0件
8. **キャプションの出典**: 「出典：警察庁 交通事故統計オープンデータ（2023年）」と年を足した（動画の最後の表示と同じ）。
9. **ナレーションの締め**: 指示書どおり「誰に送るか」で終える。キャプションは既存の形なので「〇〇へ【保存＆シェア】」。
10. **「当たり前すぎる」での入れ替え（2026-11-18 夜・ユーザーが4つの題材を選んだ）**:
   - EP22: C22（はねられた歩行者75歳以上）→ C27（歩行者×天気×昼夜）。第1位くもりの夜 5.12%（3.9倍）、第2位 晴れの夜、第3位 雨の夜。「雨の夜は夜の中でいちばん低い」は、歩行者の年齢4区分・制限速度別（30/40/50/60/その他）のどれでも雨の夜＜くもりの夜であることを集計で確かめた。理由は「雨の夜は車が慎重になるといわれます」とぼかし、くもりの夜が高い理由は「このデータだけでは分からない」とキャプションに書いた。相手に自転車・バイクを含むので「車にはねられた」とは言わず「歩行者の事故」
   - EP26: C23（自転車の人75歳以上）→ 新しい候補 C32（自転車の種類×年齢・相手は四輪だけ）。当事者種別 52＝駆動補助機付自転車。75歳以上: 電動 3.85%（571件中22件）・ふつう 1.74%（4,605件中80件）、Fisher p≈0.002。電動の64歳以下は死亡が少なく並ばない（25〜64歳は0.33%でふつうの0.31%とほぼ同じ）→ キャプションに「もっと若い年齢では差ははっきりしない」。電動とふつうで地形・衝突地点・相手の車種の割合はほぼ同じだった（場所や相手だけでは説明できない）
   - EP26 のフックは参考との比（12.4倍）ではなく「同じ年齢での比」（第1位÷第2位＝2.2倍）。指示書の「フックは倍率を出す」は守り、どの比を出すかを `hookRatio` で回ごとに選べるようにした（既定は参考との比）。順位どうしの比 `{w1w2.r}` は、画面の小数2桁の致死率で割っても同じ値になるときだけ使える（build が検査）。画面の大きな倍率も同じ比を出す（scene.js の focusRatio。フックの数字と順位どうしの比がちょうど同じときだけ）
   - EP25・EP27: 数字は同じで、フックを「60キロの道ではない」「高速道路ではない」に。EP25 の理由は「50キロの道は市街地の外での事故が多いのも特徴です」（地形の区分で 16%・60km/h は 5%）。EP27 は「高速道路の約2.6倍」と高速道路との比も言う
   - 写真: EP22・EP25 の問いの写真（雨の夜／道の端の足元）は「〇〇ではない」の前振りとしてそのまま使い、理由カードの2枚を作り直した。EP22 の安全側は1回目が右側通行に見えたので作り直した
   - 問いのあとに「〇〇ではありません。」がある回は、問いの絵を参考の文の始まりまで伸ばす（timeline.mjs）。EP25 は伸ばす前、フックが声より2.8秒早く消えていた
   - 光の位置の自動検出が昼の写真で外れた EP26 の問い（日差しの横断歩道を光と判定）と EP29 の締めは、プロンプトの fx に手で書いた
11. **レビュー（入れ替え後）で直したこと**:
   - 第1位を明かす場面の大きな倍率を、フックではなく「第1位の数字を言う文の約○倍」から選ぶ（`timeline.mjs` の focusRatio。scene.js と build が同じ関数を使い、build は声の倍率が画面の比のどれかとちょうど同じかを検査）。EP27 は声が「高速道路の約2.6倍」なのに画面が「参考の約8.3倍」だった。フックの数字の偶然の一致で EP02・EP03 の表示が変わる後退も防いだ。EP01〜20 で変わるのは EP07 だけ（前はフックの最初の数字「軽は1.8倍」を出していたが、声は「大型バイク…約21倍」）
   - EP25: 「50キロの道は市街地の外での事故が多いのも特徴」をやめた。地形の区分ごとに比べても 50km/h の道が高く（人口集中 4.89% vs 3.13%、その他の市街地 6.83% vs 0.95%、市街地の外 12.4% vs 8.9%）、地形で説明できるのは差の一部。原稿は「市街地の中でも外でも、60キロの道より高いままです」、理由はキャプションで「分からない」。danger の写真も街なかの道に
   - EP26: 75歳以上の差の多くは市街地の外（市街地 10/503 vs 61/4102・p≈0.34、市街地の外 12/68 vs 19/503・p<0.001）。原稿・理由カード・キャプションに書き、フックを「同じ75歳以上でも」に絞った。danger の写真も市街地の外の道に
   - EP22: 理由カード「事故の多くは乾いた路面」は原因に読めるので「乾いた道でも濡れた道でも高い」に（くもりの夜の中で乾燥 5.17%・湿潤 5.29%）
   - 既存の問題（今回は直さない）: 参考との比は丸める前の率どうしで出すので、画面の率どうしを割ると少しずれる回がある（EP21: 2.34/0.035＝66.8 と 67.7、EP23・24・29・30 も±0.3）。「約」の範囲として残した
