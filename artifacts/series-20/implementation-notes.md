## Deviations
1. **rate の桁**: 遭遇: 画面（Three.js）は JSON の rate どうしを割り算して倍率を出すため、小数2桁で入れると参考が小さい回で倍率がずれる。選択: EP21〜30 の rate は小数6桁で入れる（表示は2桁）。理由: 画面・原稿・キャプションの倍率を一致させるため。build_ep21-30.mjs が「JSON の数字で割った倍率＝原稿の倍率」を検査する。EP01〜20 は変えていない。
2. **0.1%未満の表示**: 0.1%未満だけ小数3桁（0.036%・0.079%）。scene.js の `rateDigits` と原稿・キャプションで同じ規則。指示書の「小数第2位まで」からの逸脱。**HTML 版（template_winning_v3.html / batch_render.mjs）は小数2桁で出すので、EP21〜30 は Three.js 版で書き出すこと**（HTML 版だと参考が 0.04%・0.08% と出て原稿と合わない）。
3. **倍率の書き方**: 原稿・注記・キャプションも画面の `formatRatio` と同じ「小数1桁で切り捨て（100倍以上は整数）」。EP04 の「約21.3倍」と同じ書き方。
4. **レビュー（1回目）で変えた定義**（数字が確認時と変わった回）:
   - EP21: C01 → C31（交差点の中の衝突を除く）。交差点の中の「前どうし」は右折車とのぶつかり等が混ざり、致死率0.28%と性質が違う（死亡94件中87件は単路）。「正面衝突」と呼ぶため除いた。46.0倍 → 69.0倍
   - EP22: 相手を四輪に限定（自転車にはねられた事故・相手不明を除く）。16.3倍 → 15.4倍
   - EP26: 相手を四輪に限定。25.0倍 → 24.9倍（切り捨て）
   - EP30: 相手を四輪に限定。7.1倍 → 6.5倍
   - EP27: 路線コード上4桁1500〜1999（主要地方道－市道）を市町村道へ。8.4倍 → 8.3倍
   - EP29: 「正面衝突」→「前どうしの衝突」。7割が交差点の中で、警察庁の「正面衝突」とは呼べない。交差点の中を除く版（C30）は第3位が条件を満たさないので C29 のまま、キャプションに定義を注記
5. **答えを伏せる**: 第1位を明かす前に出る caseTitle（HUD に0秒から）・badge・panelTitle・フック・最初の問いに、回ごとの `spoilers` の語を入れない（build が検査）。EP21「正面衝突の罠／HEAD-ON」、EP24「郊外の夜道の罠／RURAL NIGHT」を変えた。
6. **制限速度の回（EP25・EP30）**: 60km/h の道は 50km/h の道より低い（EP25 は画面にも出る。EP30 は死亡6件で並ばない）。原稿は「速くぶつかるほど命の危険は高まるといわれます」とぼかし、「速い道ほど危ない」とは言わない。EP25 のキャプションに「制限速度だけで危なさが決まるわけではなく、60km/hの道は50km/hの道より低い」、EP30 に「制限速度がもっと高い道は死亡事故が少なく比べていない」と書いた。EP30 の CTA は「車の速い道は避けて選ぶ」→「50km/hの道は特に慎重に」。
7. **テンプレートの修正（EP01〜20 の Three.js 版にも効く）**:
   - カメラ（`framed`）: 参考・第3位・第2位・全体の場面で、柱の数字が見出しにかからず（付け根が上から540px以下）、柱の名前が下380pxに入らない（付け根が上から1365px以上）ところまで引く。引くほど柱の間隔が詰まるので、注視点の高さも動かして引く量が最小の組を選ぶ。収まる回は元の位置のまま。barMax を超えて突き抜ける柱（EP01 の列車）は上の条件から外す
   - 柱の名前の箱を 240→180px、`word-break: auto-phrase`（文節で折り返す）。隣どうしの重なりを防ぐ
   - フックの左右余白を 60→120px。見出し・倍率の大きな文字は、幅が840pxを超えるときだけ縮める（`fitWidth`）
   - 検査: `threejs/check_safe_area.mjs`（見えている文字が上220px・下380px・右120pxに入っていないか、柱の数字が見出し類と、柱の名前どうしが重なっていないか）。EP01〜30 で主要な文字は0件
8. **キャプションの出典**: 「出典：警察庁 交通事故統計オープンデータ（2023年）」と年を足した（動画の最後の表示と同じ）。
9. **ナレーションの締め**: 指示書どおり「誰に送るか」で終える。キャプションは既存の形なので「〇〇へ【保存＆シェア】」。
