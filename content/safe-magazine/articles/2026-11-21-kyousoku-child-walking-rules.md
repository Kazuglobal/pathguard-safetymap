# 【保存版】国が定めた通学路の歩き方——教則「子供の安全」10項目

<!-- テンプレート: T5 実践ガイド型 (action-guide) ／ シリーズ:教則で読む通学路（1本目） ／ category: safety-tips ／ 編集カレンダー: 12〜1月「積雪凍結・年末年始の交通量」への先回り（夜・雨の章を冬仕様で読む） -->

### リード

- **何が分かったか**: 子どもに交通ルールをどう教えるかは、**国の告示で文章になっています**。「交通の方法に関する教則」（道路交通法第108条に基づく国家公安委員会告示）の第2章第9節は、タイトルがそのまま「**子供の安全**」で、保護者向けの項目が**10個**並んでいます。警察庁サイトには2026年11月6日作成の最新版（全149ページ）が掲載されています。
- **わが家にどう関係するか**: 「気をつけなさい」と言う代わりに使える、**国が示した具体的な言い方**がそろいます。10項目のうち半分は、交通安全教室では出てこない家庭の中の話（送り出す時間、呼びかけ方、歩く位置）です。
- **読むと何ができるか**: 10項目を「わが家の行動」に翻訳したチェックリスト、日没が早いこの時期に効く「夜間」「雨の日」の章の読み方、そして9月に変わった生活道路30km/hが教則にどう書かれたかが分かります。

### 結論から：子どもへの教え方は「国の文章」になっている

交通安全の話は、学校のお便りや地域の呼びかけで届くことが多く、「どこかの誰かが決めた注意事項」のように感じることがあります。

でも、おおもとは1つの公的な文書です。「**交通の方法に関する教則**」（以下、教則）です。

| 項目 | 内容 |
|---|---|
| 根拠 | 道路交通法 第108条 |
| 形式 | 国家公安委員会告示（昭和53年10月30日 告示第3号） |
| 分量 | 全149ページ（第1章〜第11章＋用語のまとめ＋付表） |
| 最新の改正 | 令和8年7月17日 国家公安委員会告示第32号 |
| 入手 | 警察庁サイトでPDFを無料で閲覧・保存できる |

教則は、巻頭で読者にこう呼びかけています。

> 「繰り返し読んで、正しい交通の方法を理解し、身に付けるとともに、友人や家族、特に子供たちにも折に触れて教えてあげるようにして下さい。」

つまり教則は、運転免許の教科書ではなく、**保護者が子どもに教えるための手引きとしても書かれている**文書です。

> 出典: 警察庁「交通の方法に関する教則」［公式発表］　データ時点: 令和8年7月17日公安告示第32号までの改正を反映した版。PDFの作成日は**2026年11月6日**、警察庁サイト上の最終更新は2026年11月12日（本記事はPDF本文を直接確認して作成しています）
>
> なお教則の本文は「しましよう」「持つて」のように**公布当時の送り仮名**で書かれています。本記事の引用は原文どおりに記載しています。

### 事実1：第2章第9節「子供の安全」は10項目［公式発表］

第2章は「歩行者の心得」で、その第9節が「子供の安全」です。保護者に向けた10項目を、原文の要点と「わが家の行動」に分けて並べます。

| # | 教則の要点（第2章第9節） | わが家の行動に翻訳すると |
|---|---|---|
| 1 | 子供の交通事故のほとんどは、道路を横断しているときや、横断しようとして飛び出したときに起きている。右左をよく見て安全を確かめてから横断を始め、横断中も車に気を付ける——この正しい横断の仕方を**繰り返し**教える。保護者自ら交通規則を守り、手本を示す | 「1回教えた」で終わりにしない。親が赤信号で渡らない |
| 2 | 交通量の多い道路や踏切の付近で子供を遊ばせたり、幼児を独り歩きさせたりしてはいけない | 遊ぶ場所を家族で決めておく |
| 3 | 子供を連れて道路を歩くときは、**保護者が車の通る側**を歩く | 並んで歩くときの左右の位置を意識する |
| 4 | 幼児は、興味のあるものや知っている人を見掛けると、いきなり道路に飛び出すことがある。しっかり手をつなぎ、目を離さない | 「知っている人を見つけたとき」が危ないと知っておく |
| 5 | 保護者が買い物や立ち話に夢中になっているときなどが大変危険。幼児が道路の向こう側にいるときは**呼び掛けない** | 向かいにいる子を呼ばず、自分が渡って迎えに行く |
| 6 | 車に乗るときは子供を先に乗せ、降りるときは保護者が先に降りる。車から子供だけを降ろすときは、子供が道路を横断しなくてもすむ位置に止める | 送迎の停車位置を「降りて横断しない側」にする |
| 7 | 子供が遊びに出るときは、**保護者に行き先を告げる習慣**をつけさせる。遠くへ行ったり、暗くなるまで遊んだりしないよう注意する | 「どこで・誰と・何時まで」を出る前に言う習慣にする |
| 8 | 子供の服や履物は活動しやすく、なるべく**明るい目立つ色**のものにする | 冬の上着・手袋・靴の色を見直す |
| 9 | 幼稚園や学校に行くときは**早めに送り出し**、忘れ物をさせないように気を付ける。時間ぎりぎりに家を出て先を急いだり、忘れ物をしてあわてて戻ったりするときに事故を起こしがち | 家を出る時刻を5分早める。前夜に持ち物を確認する |
| 10 | 子供が道路や踏切を横断しようとしているときは、そばにいる人が安全に横断できるようにしてあげる | 自分が他の家の子を見かけたときにできること |

> 出典: 警察庁「交通の方法に関する教則」第2章第9節「子供の安全」1〜10［公式発表］　データ時点: 令和8年7月17日改正版

**この10項目の特徴は、半分が「道路の上の話」ではないこと**です。9番の「早めに送り出す・忘れ物をさせない」、7番の「行き先を告げる習慣」、5番の「向こう側にいる子を呼ばない」は、玄関や家の中で決まることです。

危険を指摘して終わらせないために、この記事では**各項目をそのまま家庭の行動に置き換えたチェックリスト**を後半に用意しました。

### 事実2：日没が早いこの時期は「第5節 夜間歩くとき」を読む［公式発表］

同じ第2章には、季節ごとに読み返す価値がある節があります。「第5節 夜間歩くとき」の5項目です。

1. 夜間は、**歩行者から自動車のライトが見えても、運転者から歩行者がよく見えないことがある**。特に雨などでアスファルトの路面がぬれているときは、歩行者が見えにくくなる
2. 夜は運転者も疲れて注意力や視力が低下し、歩行者も自動車のスピードや遠近が分からなくなる。横断するときや自動車と擦れ違う場合は、昼間より一層注意する
3. **道路の中央付近にいる歩行者は、両方から来る自動車のライトで運転者から瞬間的に見えなくなることがある**。中央付近で立ち止まらないよう、横断する前に十分気を付ける
4. 信号機のない場所で横断するときは、運転者から横断していることがよく分かるよう、**道路照明のあるところなどできるだけ明るい場所を選ぶ**
5. 夜間歩くときは、明るい目立つ色の衣服を着用したり、**靴、衣服、カバン、つえなどに反射材を付ける**

**わが家への意味**: 1番は、子どもが「車が見えているから大丈夫」と考えてしまう理由そのものです。「**見えている」と「見えてもらえている」は違う**——この一言は、教則の文章がそのまま使えます。3番の「道路の真ん中で止まらない」は、横断中に迷って立ち止まる場面に直結します。

冬は日没が早く、下校や習い事の帰りがこの時間帯に重なります。SAFE MAGAZINEでは[秋の夕方に効く反射材の備え](/safe-magazine/autumn-twilight-reflective-gear)と[秋の運動期間中に夜の歩行中死者が増えていたこと](/safe-magazine/autumn-campaign-2026-night-pedestrians)を取り上げました。教則の第5節は、その**根拠になっている考え方**の部分です。

### 事実3：雪や雨の日は「第6節 雨の日などに歩くとき」の2項目［公式発表］

1. 雨の日などは視界が悪くなるので、レインコートなどの服装は、運転者から見やすいように**明るい目立つ色**のものにする。また、**前が見えにくくなるような傘の差し方**は危険なのでやめる
2. 雨の日などは路面が滑るため、自動車の停止距離が長くなったり、歩行者も転びやすくなったりして危険。**無理な横断や飛び出しをしない**

**わが家への意味**: 2番の「自動車の停止距離が長くなる」は、雪や凍結の朝にそのまま当てはまります。**雨や雪の日は、車が止まれる距離が晴れの日より長い**——つまり「いつもは止まってくれる横断歩道」でも、同じようには止まれません。雪の日の通学路については[雪山で見通せない交差点の備え](/safe-magazine/winter-snow-ice-school-route)も併せてご覧ください。

### 事実4：9月施行の生活道路30km/hは、教則の「運転者の章」に書き込まれた［公式発表］

今年の改正でもう1つ確認できたことがあります。2026年9月1日に施行された**生活道路の法定速度30km/h**が、教則の第5章第4節「安全な速度」に反映されています。

- 「標識や標示で指定されていないときは、主として地域住民の日常生活に利用される生活道路のような、**中央線などがない一般道路では時速30キロメートル**、それ以外の一般道路では時速60キロメートルを超えて運転してはいけません」
- 「決められた速度の範囲内であつても、道路や交通の状況、天候や視界などをよく考え、**特に生活道路においては、歩行者が優先という意識を持つて、安全な速度で走りましよう**」

対象となる「中央線などがない一般道路」の定義も、注8として新しく追加されました。いずれも改正履歴に**令和8年公安告示第32号**（2026年7月17日）と付記されています。

**わが家への意味**: 30km/hの規制は「標識がない住宅街の道」が対象で、見分けにくいことがSAFE MAGAZINEの[見分ける3条件の記事](/safe-magazine/30kmh-road-identification)でお伝えしたポイントでした。教則の改正で加わった「**生活道路においては歩行者が優先という意識を持って**」という一文は、保護者が運転するときの心構えとしても、子どもに「この道では車がゆっくり走ることになっている」と説明するときの根拠としても使えます。

ただし、**ルールが変わったことは、子どもが飛び出してよい理由にはなりません**。教則の第2章第9節1が繰り返し教えるよう求めている「右左をよく見て安全を確かめてから横断を始め、横断中も車に気を付ける」は、速度が下がっても変わりません。

### 今すぐできること（保存版チェックリスト）

教則の10項目を、そのまま家庭の行動に置き換えたものです。印刷かスクリーンショットで、冷蔵庫や玄関に貼って使ってください。**全部やる必要はありません。できていない行にだけ印をつけてください。**

**玄関で決めること**

- [ ] 家を出る時刻を**5分早める**（教則9：時間ぎりぎりとあわてて戻るときが危ない）
- [ ] 持ち物は**前の晩に**子ども自身が確認する（教則9：忘れ物で戻るのを防ぐ）
- [ ] 遊びに出るときは「**どこで・誰と・何時まで**」を言ってから出る（教則7）
- [ ] 冬の上着・手袋・靴に、**明るい色か反射材**が入っているか見る（教則8・第5節5）

**道の上で決めること**

- [ ] 親子で歩くときは、**親が車道側**を歩く（教則3）
- [ ] 道の向かい側にいる子を**呼ばない**。自分が渡って迎えに行く（教則5）
- [ ] 送迎の停車位置は、子どもが**降りてから横断しなくてすむ側**にする（教則6）
- [ ] 横断は、**横断歩道か信号のある交差点**で。近くにあるときはそこまで歩く（第2章第3節1）
- [ ] 信号のない場所で渡るときは、**道路照明がある明るい場所**を選ぶ（第5節4）
- [ ] 横断中に迷っても、**道路の真ん中で立ち止まらない**（第5節3）

**雨・雪の日に足すこと**

- [ ] レインコートは**明るい目立つ色**を選ぶ（第6節1）
- [ ] 前が見えなくなる**傘の差し方をしない**（第6節1）
- [ ] 「車はいつもより止まれない」と出発前に一言伝える（第6節2）

### 今週、子どもに伝えたい一言

> 「車のライトが見えても、運転している人からきみが見えているとは限らないよ。だから、明るい場所で渡ろうね。」

教則第2章第5節1の内容をそのまま子ども向けにしたものです。暗い帰り道に、親が自分の経験として話すと伝わりやすくなります。

### 教則を自分で確認する方法

全国共通の文書なので、どこに住んでいても同じものが確認できます。

1. **警察庁サイトで探す**: 検索キーワードは「警察庁 交通の方法に関する教則」。警察庁の「交通安全のための情報」ページに「交通の方法に関する教則」のPDFリンクがあります
2. **読む順番**: 149ページ全部を読む必要はありません。保護者がまず読むのは**第2章（歩行者の心得**）、自転車通学の子がいる家庭は**第3章（特定小型原動機付自転車や自転車に乗る人の心得**）です
3. **改正を見分ける**: 各項目の末尾に「（令８公安告32・一部改正）」のような履歴が付いています。「**令８」は令和8年＝2026年の改正**です。ここを見れば、どこが最近変わったのかが分かります
4. **お住まいの地域の教室を探す**: 都道府県警察や自治体が開く交通安全教室では、この教則の内容を実地で練習できます。検索キーワードは「（市区町村名） 交通安全教室 こども」、または通っている学校・園に「今年度の交通安全教室はいつか」を聞くのが早道です

### PathGuardianでできること

チェックリストの「道の上で決めること」は、地図に記録しておくと翌年も使えます。PathGuardianの地図で通学路のうち**横断する場所**を記録し、夕方に親子で歩いて「暗くて見えにくい」「車が止まってくれない」と感じた場所を**危険箇所として報告**しておいてください。教則第5節4の「明るい場所を選ぶ」は、実際の道で明るい場所がどこかを知らないと実行できません。記録しておけば、来年の冬も同じ道で見返せます。
