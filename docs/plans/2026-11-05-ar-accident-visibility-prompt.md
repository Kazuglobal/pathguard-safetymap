# AR実事故表示の改善プロンプト（2026-11-05）

## 背景（ユーザー報告・実機スクショ）
- 事故データが近くにあるのに、AR画面に出てこない。
- 出ても「実事故・442m」というチップが画面上部に浮いているだけで、どこが事故現場なのか分からない。

## 調べて分かった原因（components/map/ar-real-risks.tsx / lib/ar-risk-data.ts）
1. **画角の外の事故を捨てている**: `projectARAccidents` は方角が取れると、カメラの画角（±fov/2 ≒ ±30°）の外の事故を除外する。
   後ろ・横にもっと近い事故があっても、マーカーにも下のパネルにも一覧にも出ない。パネルの「最寄り」も画角内の最寄りにすぎない。
2. **同じ方向の事故を1つにまとめている**: マーカーは横位置だけで約7列にまとめ、列ごとに最寄り1件のチップしか出さない。
3. **高さ（距離）を表していない**: マーカーの縦位置は画面の 25〜33% 固定。地面のどこか、手前か奥かが分からない。
4. **方向の言葉がない**: パネルに「約442m先」しかなく、どちらを向けばよいか・どの方角か・交差点かどうかが書かれていない。

## 改善プロンプト（実装の指示）
```
AR危険箇所ビューの「実事故」表示を、利用者が現場の位置を目で特定できるように直す。

【必須】
1. 表示距離内の事故は、画角の外でも取りこぼさない。
   - 画角内 = 画面上のピン。画角外 = 画面の左右の端に「◀ 左に3件・最寄り120m」「右に…▶」、
     真後ろ寄り（|角度|>135°）は「後ろに…」として出す。タップでその方向の最寄りを選ぶ。
   - パネルと「近くの実事故」一覧は、画角に関係なく近い順の全件（上限20件）を出す。
   - 選んだ事故が画角の外なら「右へ約45°向くと見えます」と向き直しを案内する。
2. ピンは地面に立てる。
   - 端末の傾き（tiltRef）から仰角を出し、地面上の距離 d の点の見え方（俯角 atan(1.4m/d)）で縦位置を決める。
     傾きが取れないときは水平（画面の中央の高さ）に置く。ドックや上部UIに隠れないよう縦位置は範囲内に収める。
   - チップの下に棒と地面の影（楕円）を描き、近いほど大きく、遠いほど小さくする。
   - 同じ方向でも距離が大きく違う事故は別のピンにする（横×距離の両方でまとめる）。
3. 方向の言葉を出す。
   - パネル: 「正面 / 右前 / 右 / 右後ろ / 後ろ …」＋方位（南南西など）＋「約442m」。
   - 道路形状（roadShape: 交差点など）が記録にあれば出す。原因を推測で書かない。
4. 画面右上に小さなレーダー（自分を中心に、表示距離内の事故を点、画角を扇形）を出す。

【禁止】
- 事故の位置・原因・件数の捏造や丸め込み（記録にない情報は出さない）。
- 画角外の事故を「0件」と見せること。
- 既存の文言・注意書き（未収録は安全という意味ではない 等）や、パネルのたたみ機能の削除。

【完了条件】
- vitest: tests/unit/lib/ar-risk-data.test.ts と tests/components/map/ar-real-risks.test.tsx が全緑（新規テスト含む）。
- tsc --noEmit がこの変更でエラーを増やさない。
- 画面外の事故が端の案内とパネルに出ること、ピンの縦位置が距離と傾きで変わることをテストで確認する。
```
