# PathGuardian 紹介パンフレット(A4縦・両面)画像プロンプト集

作成日: 2026-11-13 / 対象: 保護者・学校・PTA・自治体向けの配布用パンフレット

## 0. 制作方針

- **画像はAI生成、文字・ロゴ・QR・数字は後からコードで入れる**(日本語を画像に焼き込むと崩れ、修正もできないため)。
  下の A〜E の素材プロンプトはすべて「文字なし」指定。
- アプリ画面は AI に描かせず、**実機スクリーンショット**をスマホ枠(素材B)にはめ込む。
- キャラクター「ルペ」は AI に再現させず、リポジトリ内の既存アセットを使う。
- 実績数値・導入校数などの「偽実績」は載せない(プロダクト方針)。
- 生成サイズ: A4全面 300dpi = **2480×3508px**(裁ち落とし込みは 2551×3579px)。生成AIの上限が低い場合は 2:3 縦の最大解像度で出して後でアップスケール。

### 共通スタイル(全プロンプトの末尾に付ける)

```
スタイル: 日本の小学校・住宅街の実写写真。朝のやわらかい自然光、ハイキーで明るく清潔感のある色調。
配色はクリーム色(#FBF3E6)を基調に、深いグリーン(#159E73)を差し色、アクセントにあたたかいオレンジ(#F4801F)。
人物は自然な表情の普通の日本人家族・児童(モデル風の美男美女にしない、後ろ姿や横顔中心)。
禁止: 文字、ロゴ、数字、看板の文字、透かし、枠線、UI画面、歪んだ手指、過度なボケ・レンズフレア、CG感。
```

### 配色・書体(文字入れ時)

| 用途 | 指定 |
|---|---|
| メイン | グリーン #159E73 |
| 背景 | クリーム #FBF3E6 / 白 #FFFDF7 |

| 書体 | 見出し・本文とも丸ゴシック系(Zen Maru Gothic)。アプリの「たんけんノート」の世界観に合わせる |

## 2. 裏面(うら)― 「わかってもらう」面

### レイアウト(mm)

| # | 機能名 | 説明(仮) | アイコンの題材 |

| 3 | 通学路の登録 | 家族で通学路を地図に登録・管理 | 曲がった道と旗 |
| 4 | 安全ニュース | 通学路の安全ニュースを毎日お届け | 新聞とベル |
| 5 | バッジ・ミッション | 続けるほど身につく、楽しく学べるしくみ | メダル(星) |

```

各アイコンは同じ大きさの淡いパステル色の円(薄いグリーン、薄いオレンジ、薄い水色、薄い黄色を順に)の中に、

下段左から: 4) 折りたたんだ新聞と小さなベル  5) 星のついたメダル  6) 1枚のカードとハート
すべて同じ線の太さ・同じ画風で統一。円どうしは重ならず、周囲に十分な白い余白を取る。
```

## 3. 確定が必要な項目(すべて仮)

- キャッチコピー、リード文、機能説明、見出しの文言
- QRコードのリンク先URL
- 運営者名・問い合わせ先(メール/電話)
- 料金表記(「無料ではじめる」と書いてよいか)
- 配布対象(保護者向け中心か、学校・自治体向け中心か)― 裏面下部の文面が変わる

## 4. 生成後の流れ

1. 素材 A〜E を生成し、`docs/brochure/photos/` に `hero.jpg` / `phone.png` / `icons.png` / `steps.png` / `family.jpg` の名前で置く
2. アプリの実機スクリーンショット(地図画面)を1枚用意
3. 文字入れ(ReportLab)→ プレビューPDF → 裁ち落とし3mm・トンボ付きの印刷用PDF
