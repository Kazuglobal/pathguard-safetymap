### 13-b. 根本原因

生成の6件すべてが**同じ HTTP エラー**で落ちている（`gemini-3.1-flash-image-preview` と `gemini-3.1-flash-lite-image` の**両方のモデル候補で同一**）:

```

  gemini-3.1-flash-image-preview#1: HTTP 402: {
    "error": { "code": 402,
      "message": "Your prepayment credits are depleted. Please go to AI Studio at
                  https://ai.studio/projects to manage your project and billing. ..." }
  | gemini-3.1-flash-lite-image#1: HTTP 402: （同文）
...
失敗 6 件。記事が参照する画像が欠落したままです。
```

**つまり、ワークフロー・APIキー・プロンプト・参照の書き方のいずれにも問題はなく、Google AI Studio 側のプリペイド残高が尽きている。**

- **安全フィルタによる拒否ではない**（402 は課金エラー。ブロックなら別のコードになる）
- **本セッションの参照の書き方は正しかった**（`ensure-news-image-refs.ts` が「補完0件・規約どおり」と判定している）
- **プレースホルダ画像は作られていない**（`pushed=false`／生成0件）。**本番に暫定画像が出る事故にはなっていない**

### 13-c. 対応のお願い（マージ前に必要）

1. **Google AI Studio（https://ai.studio/projects）でプリペイド残高を補充する**（または課金設定を見直す）
2. そのうえで、**GitHub の Actions 画面から「School Route News Images」を手動で再実行**する（`workflow_dispatch`。既定の `figures: false` のままでよい。参照は既に揃っているため、不足している6件だけが生成される）
3. 再実行が**成功**し、ブランチに `chore(news): 通学路ニュースの画像を生成して追加` のコミットが積まれ、`thumbnail coverage` の3テストが緑になったことを確認してから **PR #318 をマージする**

> **残高を補充せずにマージすると、4本の記事が画像なし（参照切れ）で本番に出る**。`thumbnail coverage` は参照切れを検出するためのゲートなので、**赤のままマージしないこと**。
