### 画像について（スケジュールプロンプトの指示と `main` の実装の矛盾）

**スケジュールプロンプトは「Step 5 の画像生成はスキップし、`thumbnailUrl` フィールド自体を書かない（型は optional で、release-readiness テストも未設定ならスキップするため検証は緑になる）」と指示しているが、これは `main` の実装と一致しない。**

`tests/unit/lib/school-route-news-release-readiness.test.ts` の `describe("thumbnail coverage")` は次を無条件に検査する:

```ts
it("gives every news item a thumbnailUrl whose file exists", () => {
  for (const item of NEWS_ITEMS) {
    expect(item.thumbnailUrl, `${item.slug}: thumbnailUrl is missing`).toBeTruthy()
    ...
```

つまり **`thumbnailUrl` を省略すると `toBeTruthy()` が落ちてテストが赤になる**。プロンプトは同時に「Step 7 の検証ゲート（緑になるまで完了と言わない）」も要求しているため、2つの指示は同時に満たせない。**これは前回レポートの申し送り D-3 と同じ指摘で、3回連続である。**

**今回の処理（前回と同じ方針）**: ImageMagick で **slug ごとに異なる抽象プレースホルダー画像を新規生成**し、`thumbnailUrl` を記載した。

- 出力: `public/images/school-route-news/thumbnails/{slug}.jpg`（既存記事と同じ 1408x768・JPEG）
- **他記事の画像の流用はしていない**（5枚の md5 がすべて異なることを検算済み）
- **存在しないパスも書いていない**（ファイル実在を検算済み）
- 絵柄はカテゴリカラーに合わせた抽象図形（`suspicious`=オレンジ警戒 / `policy`=紫の落ち着き）＋横断歩道を思わせる抽象ストライプ。**事故現場・不審者本人・人物は一切描いていない**。配置は slug のハッシュから決定的に変化させている
- **これらは本来の品質の画像ではない。マージ前に各 slug の画像をローカルで生成して差し替えること**

**差し替えが「推奨」ではなく「必須」である理由（Codex レビュー #235 の指摘により追記）**: `getLandingNewsPreview()` は `NEWS_ITEMS` の最新5件をそのまま選ぶため、**今回の新規5本がランディングページのニュース欄を丸ごと占める**。つまりプレースホルダーのまま本番にマージすると、**ランディングのニュース欄が5枚すべて未完成画像で埋まる**。しかも `thumbnail coverage` テストは「ファイルが実在するか」しか見ないため**この状態でも検証ゲートは緑のまま通る**。テストでは検知できない種類の劣化であり、マージ前の差し替えを人間が担保する必要がある。

なお Codex は5枚を `near-identical` と評したが、これは不正確である。**配置は slug の SHA-256 から決定的に変えており、5枚の md5 はすべて相異する**（カテゴリ別の配色も `suspicious`=オレンジ／`policy`=紫で異なる）。ただし**同一テンプレートから生成しているため作風が似ている点は事実**であり、「記事ごとの内容を表す画像になっていない」という指摘の本質は正しい。

差し替え対象の5ファイル:

```
public/images/school-route-news/thumbnails/kochi-city-schoolway-indecent-exposure-arrest-20261007.jpg
public/images/school-route-news/thumbnails/sagamihara-minami-shimomizo-children-confinement-20261005.jpg
public/images/school-route-news/thumbnails/matsue-higashitsuda-wrist-grabbed-20261006.jpg
public/images/school-route-news/thumbnails/tsuru-schoolway-joint-inspection-20261006.jpg
public/images/school-route-news/thumbnails/namerikawa-schoolway-safety-inspection-20261007.jpg
```

なお `GEMINI_API_KEY` はこの実行環境に設定されていない（値は一切出力していない）。設定されれば `scripts/generate-missing-images.ts` がクラウド環境でも動く可能性が高い。
