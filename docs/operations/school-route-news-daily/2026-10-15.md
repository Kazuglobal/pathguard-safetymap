## 4. Step 5: 画像

### 4-a. スケジュールプロンプトの指示と `main` の実装の矛盾（5回連続）

スケジュールプロンプトは「`thumbnailUrl` フィールド自体を書かない。型は optional で release-readiness テストも未設定ならスキップする」と指示している。**この前提は `main` の実装と一致していない。**

```
tests/unit/lib/school-route-news-release-readiness.test.ts
describe("thumbnail coverage") > it("gives every news item a thumbnailUrl whose file exists")
  expect(item.thumbnailUrl, `${item.slug}: thumbnailUrl is missing`).toBeTruthy()
```

`toBeTruthy()` は条件なしで全 `NEWS_ITEMS` に対して実行されるため、**`thumbnailUrl` を省略すると必ず赤になる**。同じプロンプトが「Step 7 の検証ゲートが緑になるまで完了と言わない」も求めており、2つの指示は同時に満たせない。

### 4-b. 今回の対応（前回と同じ判断）

**検証ゲートを緑にすることを優先し、slug ごとに新規作図した暫定サムネイルを設定した。** 他記事の画像の流用は行っていない（md5 が5件とも異なることを確認済み）。

- `GEMINI_API_KEY` は**この実行環境に設定されていない**（値は一切出力していない）ため、本生成は実行できない
- ImageMagick（`convert`）は利用できるため、**カテゴリのトーンと通学シーンの要素（黄色い帽子・ランドセル・横断歩道・駆け込み先の家／信号機／見守りの旗）を持つ作図**を slug のハッシュで構図を変えて生成した
- 事故現場・不審者本人・顔・負傷・文字・数字は一切描いていない（Step 5 の作画要件）
- 拡張子は **`.jpg`** にそろえた。PR #253 の指摘のとおり、`main` の `scripts/generate-missing-images.ts` は**JPEG しか受け付けない**ため、`.png` のままでは本生成に差し替えられなくなる

**マージ前に差し替えが必要なファイル（5件）**

```
public/images/school-route-news/thumbnails/kumamoto-kita-two-days-stalking-20261015.jpg
public/images/school-route-news/thumbnails/ofunato-masaki-bicycle-hitandrun-20261011.jpg
public/images/school-route-news/thumbnails/asahikawa-higashikou-voice-call-20261008.jpg
public/images/school-route-news/thumbnails/tendo-ekinishi-candy-lure-voice-call-20261002.jpg
public/images/school-route-news/thumbnails/gifu-schools-intruder-drill-20261015.jpg
```

ローカルでの差し替えコマンド（`GEMINI_API_KEY` のある環境）:

```bash
npx tsx scripts/generate-missing-images.ts news
```

**注意**: `main` のこのスクリプトは「ファイルが実在しない画像」だけを対象にするため、**上記5件は実在してしまっており、このままでは差し替え対象にならない**。差し替える際は該当ファイルを先に削除するか、**PR #253（暫定画像の登録機構）を先にマージする**必要がある。PR #253 がマージされた場合、本PRの5件は `scripts/image-placeholders.json` に未登録のままなので、**登録の追記が必要**である（要追跡 D-1）。
