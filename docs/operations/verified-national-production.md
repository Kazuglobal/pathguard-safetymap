# 全国集計の本番公開

対象版は `national-current-rule-v1-20261014`。原事故2,182,298件と
割り当て329,033件・未確定1,842,634件・対象外10,631件を照合した限定規則による集計。
全地点の現地確認、事故に遭う確率、歴史的地域対応の一括承認を意味しない。
出典規則と保留条件は `current-geometry-rule-v1.md` を参照。

検証根拠は `data/national-release-v1/` の固定ハッシュ3記録。
47都道府県の未ログインHTTP、全国TOP10、千葉県→柏市→自転車→詳細、
一覧と地図の双方向同期、同順位、追加20件、URL共有・戻る・進む、
0件・未収録・地域対応準備中、ブラウザー内503再現と再試行、390×844と1280×900、
16px本文・44px地図操作を実データで確認した。連続条件変更の修正後CIは
38548366929で成功。画面QAは元データの未確定を承認するものではない。

公開は最新mainの `Cloudflare Production` のみ。通常の本番ソースガードに加え、
登録スクリプトも既存ガードを取得前・登録前・有効化前に実行する。
ローカルからは本番登録・有効化・release公開を実行しない。任意の対象入力を設けない。
登録先は `pathguardian-traffic` (`84db49b6-e9f4-4886-8319-2b7d32d59438`) に固定する。

新しいWorkerのビルド・公開が成功した後、GitHubの固定release412514430から
固定asset IDを取得し、manifest・84SQL・gzip・ライセンスの全SHA256を照合する。
圧縮DBは解凍ストリームのSHA256と335,863,808bytesも確認する。
原事故IDを含む監査テーブルは登録しない。約336MBの6集計表のみを使用する。

新規版は非公開でINSERTし、6表1,305,916行・原事故照合・地点別合計・47都道府県・
メタデータ・外部キーを確認する。既存版にはデータを追加・置換・削除しない。
途中登録版があれば全件検証に失敗して停止する。全部登録済みの非公開版は
全件検証後、release／有効化段階だけを再開できる。
有効化前に6集計表だけを読み取り専用exportし、固定ハッシュの機械可読DBと主キー順に
全1,305,916行・全列を照合する。地点座標や条件別件数が変われば、総件数が同じでも拒否する。
exportのローカル再現は許可された6表へのINSERTだけを認め、DELETE/UPDATE/ATTACHを拒否する。
SQL書き出しのREAL列だけに差がある場合は、その地点を64 IDずつD1から直接読み取り、
配布DBの座標と数値として厳密に一致することを確認する。許容誤差による承認はしない。
直接取得した確認ページと確認地点数を保存し、整数・文字列・条件別件数は引き続き
全行比較で一致を要求する。SQL書き出しと直接取得を組み合わせた照合であることを
`full-row-verification.json` に記録する。

全国品質確認後、同じProductionワークフローが利用条件付き配布releaseを公開する。
機械で読める道路由来データとODbL利用条件の公開を確認してから、該当版だけを有効化する。
画面の「数え方とデータについて」から配布データに進める。
不変の元集計metadataは保持し、画面検証と公開承認は本番実行receiptに記録する。

失敗時は自動ロールバック・削除・上書きを行わない。取り込み証拠を90日間のCI artifactへ
保存し、ログ／元配布資産を保持する。公開後は47地域のランキング、柏市の自転車詳細、
共有条件、データ配布リンクと本番API認証境界を確認する。
