子ども向けの画面は、大人向けの画面の文字を大きくして、色をポップにすれば作れる。
そう思って作った最初のバージョンは、我ながら「使われない画面」の見本のようなものでした。
これは、通学路の安全アプリを個人開発する私が、「大人UIの縮小版」を捨てて、紙質感とキャラクターに辿り着くまでの記録です。
子ども向けのものを作る人に、転用できる教訓を3つ持ち帰ってもらえたら嬉しいです。

## 「文字を大きくすればいい」と思っていた

私はPathGuardianという、通学路の危険を見える化する家族向けのWebアプリを個人開発しています。技術スタックはNext.js + React + Mapbox GL + Supabase。地図に危険報告や事故データを重ねる、どちらかといえば「大人の道具」らしいアプリです。

そこに「きけんハンター」という子ども向けの機能を作ることにしました。通学路の写真をアップすると、AIが危険箇所と安全設備を検出して、写真の上に色分けで描いてくれる機能です。

最初のバージョンのUIは、正直に言えば既存画面の流用でした。白背景にグレーのカード、ゴシック体、「解析が完了しました」というシステムメッセージ。変えたのは文字サイズとボタンの大きさくらい。当時の私は「子ども向け=大きくて、分かりやすくて、少しカラフル」だと思っていたのです。

## 子どもの目線で見直して気づいた、3つのズレ

デザインを見直す過程で、大人UIの流用には少なくとも3つのズレがあると気づきました。

**1つ目は「言葉」のズレ。**「解析」「検出」「危険箇所」。大人には正確で便利な言葉が、低学年の子には読めない・意味の取れない言葉でした。文字サイズを上げても、読めない漢字は「大きく読めない」だけです。

**2つ目は「トーン」のズレ。**危険を赤い警告で並べる画面は、大人には情報でも、子どもには「怒られている」体験に近くなります。開くたびに「危ないからダメ」と言われる画面を、子どもが自分から開きたくなるはずがありません。

**3つ目は「質感」のズレ。**白背景+グレーのカードは、業務ツールの記号です。子どもの日常にある紙・ノート・シールのような手触りがどこにもなく、「自分のもの」と感じられる余地がありませんでした。

まとめると、問題はUIの部品ではなく、体験の主語でした。大人UIの縮小版は「大人の道具を子どもに貸している」画面であって、「子どもが主人公」の画面ではなかったのです。

## 「たんけんノート」という答え

作り直したデザインのコンセプトは「たんけんノート」。危険を探すという行為を、探検の記録帳をつける遊びとして再設計しました。

具体的な設計判断はこうです。

- **フォントはZen Maru Gothic。**丸ゴシックのやわらかさに合わせて、画面の文言もひらがな多めに書き直しました。フォントだけ替えても、言葉が硬いままではちぐはぐになります。
- **紙質感・手書き風の画面。**白いカードをやめて、紙のテクスチャと手書き風のあしらいに。デジタルの画面の中に「ノート」の手触りを持ち込みました。
- **AI相棒「ルペ」。**検出結果を、システムメッセージではなくキャラクターの「ルペ」が伝える形にしました。同じ指摘でも、システムに警告されるのと相棒に教えてもらうのとでは、受け取る体験がまるで違います。
- **危険は赤、守ってくれるものは緑。**AIは危険だけでなく安全設備も検出して、緑で描き分けます。劣化したブロック塀のような見落としがちな危険も拾いつつ、「見つけたもの」の半分がポジティブなら、探すこと自体が楽しくなります。
- **安全スコアとミッション・バッジ。**写真ごとに安全スコアを算出し、ミッションやバッジで「また探したい」という気持ちを支えます。

*(▼ここにAfter画像: たんけんノートUIのスクリーンショット)*

底にある設計思想はひとつだけです。危険探しを「怒られて覚える」から「見つけて楽しい」に変えること。子どもの目線の高さはだいたい115cm。その高さから見える世界を、叱られる場所ではなく、探検のフィールドにしたかったのです。

## 一般化できる教訓3つ

この経験から、子ども向けUIについて一般化できると思う教訓は3つです。

**教訓1: 縮小・拡大ではなく「主語の交換」をする。**文字サイズやボタンの大きさは調整であって、設計ではありません。「誰が主人公の画面か」を入れ替えると、フォントも言葉も構造も、全部が連動して変わります。

**教訓2: フォント・語彙・トーンはセットで変える。**丸ゴシックにしただけの画面は、スーツ姿に丸い眼鏡をかけたような中途半端さが残ります。Zen Maru Gothicにするなら、文言はひらがなへ、警告は語りかけへ。まとめて揃えて初めて世界観になります。

**教訓3: 指摘はシステムではなくキャラクターに言わせる。**同じ内容でも、無人のアラートは叱責に、相棒の言葉は発見になります。危険のようなネガティブな情報を扱うプロダクトほど、「何を伝えるか」と同じくらい「誰の声で伝えるか」が体験を決めます。

この3つは、子ども向けに限らず「使うことを強制できない相手」に向けたプロダクト全般に効くはずです。

## おわりに

大人UIの縮小版は、子どもには通用しませんでした。
必要だったのは縮小ではなく、主語・言葉・質感の作り直し。
その軸は「怒られて覚える」を「見つけて楽しい」に変えることでした。

もしお子さんと通学路を歩く機会があれば、「危ないところ探し」ではなく「守ってくれるもの探し」から始めてみてください。ガードレール、横断歩道、カーブミラー。見つけるのが楽しくなると、危険への感度も自然に育っていきます。
