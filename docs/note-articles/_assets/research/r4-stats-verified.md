## 1. 「魔の7歳」— 歩行中の交通事故死傷者数は7歳が突出 【使用可】

- **数値**: 2020年〜2024年の5年間で、歩行中の交通事故死傷者数が最も多い年齢は**7歳**(5年間合計 3,436人)。
- **出典名**: 警察庁の交通事故統計に基づく分析(「魔の7歳」の呼称・分析の初出は交通事故総合分析センター(ITARDA)「ITARDA INFORMATION 交通事故分析レポート No.116」)
- **出典URL**:
  - ITARDA レポートNo.116: https://www.itarda.or.jp/contents/151/info116.pdf
  - 2020-24年の数値を報じた資料: https://prtimes.jp/main/html/rd/p/000000011.000061397.html / https://www.nikkei.com/article/DGXZQOUE2753W0X20C25A3000000/
- **データ年次**: 2020年〜2024年(3,436人)。ITARDA No.116自体は2015年データ(7歳の死傷者約1,400人、同年代で突出)に基づく2016年発表。
- **表現例**: 「歩行中の交通事故死傷者数を年齢別に見ると、7歳が最も多く(2020〜2024年の5年間合計で3,436人)、『魔の7歳』とも呼ばれています(警察庁統計・交通事故総合分析センターの分析より)。」
- **注意**: 「成人の2.5倍」「高齢者の2倍」という倍率表現は一次資料(PDFが画像形式)で直接確認できなかったため使わない。

## 2. 小学生の歩行中事故が多い時間帯(下校時間帯への集中) 【使用可】

- **数値**: 小学生の歩行中の死者・重傷者(令和2年〜令和6年合計)は、通行目的別で**下校中が484人(25.8%)と最多**。登校中232人(12.4%)と合わせ、**登下校中が716人(38.2%)**を占める。時間帯別では**14時〜15時台が最多**。
- **出典名**: 内閣府「令和7年版交通安全白書」特集(警察庁資料に基づく)
- **出典URL**: https://www8.cao.go.jp/koutu/taisaku/r07kou_haku/zenbun/genkyo/feature/feature_1_1.html
- **データ年次**: 令和2年(2020年)〜令和6年(2024年)の合計
- **表現例**: 「小学生が歩行中に亡くなったり大けがをしたりした事故の約4割(38.2%)は登下校中に起きており、特に下校中(25.8%)が最多です(令和7年版交通安全白書)。」
- **参考(同白書・別年次)**: 平成29年〜令和3年合計では時間帯別は「16時〜17時台が最多、次いで14時〜15時台」(令和4年版交通安全白書: https://www8.cao.go.jp/koutu/taisaku/r04kou_haku/zenbun/genkyo/feature/feature_01_1.html )。年次で最多時間帯が変わるため、引用時はどの白書かを明記する。

## 3. 新1年生・入学直後(5〜6月)の事故傾向 【使用可】

- **数値**: 小学1年生の歩行中の死者・重傷者(令和2年〜令和6年合計)は、**4月27人に対し6月は40人**と、1学期の5月・6月に多くなる傾向。平成29年〜令和3年合計でも4月49人→5月63人と増加。
- **出典名**: 内閣府「令和7年版交通安全白書」/「令和4年版交通安全白書」
- **出典URL**: https://www8.cao.go.jp/koutu/taisaku/r07kou_haku/zenbun/genkyo/feature/feature_1_1.html / https://www8.cao.go.jp/koutu/taisaku/r04kou_haku/zenbun/genkyo/feature/feature_01_1.html
- **データ年次**: 令和2年〜令和6年合計(および平成29年〜令和3年合計)
- **表現例**: 「小学1年生の歩行中の死者・重傷者は、入学直後の4月より学校生活に慣れてきた5〜6月に多くなる傾向があります(4月27人に対し6月40人・2020〜2024年合計、令和7年版交通安全白書)。」

## 4. 学年別・登下校中の事故件数 【使用可】

- **数値(学年別)**: 歩行中の死者・重傷者(令和2年〜令和6年合計)は**小学1年生446人・2年生453人が特に多く**、学年が上がるにつれて減少。自転車乗用中は逆に小学6年生が282人と最多。
- **数値(通行目的別)**: 登校中232人(12.4%)+下校中484人(25.8%)=登下校中716人(38.2%)。※項目2と同一データ。
- **数値(行動別・参考)**: 歩行者側に何らかの違反があった場合、**飛び出しが36.2%で最多**(平成29年〜令和3年合計、令和4年版白書)。
- **出典名**: 内閣府「令和7年版交通安全白書」(警察庁資料)
- **出典URL**: https://www8.cao.go.jp/koutu/taisaku/r07kou_haku/zenbun/genkyo/feature/feature_1_1.html
- **データ年次**: 令和2年〜令和6年の合計
- **表現例**: 「歩行中の死者・重傷者は小学1・2年生に集中し(2020〜2024年合計でそれぞれ446人・453人)、低学年ほどリスクが高いことが分かります(令和7年版交通安全白書)。」

## 5. 子どもへの声かけ事案・不審者情報の件数規模 【条件付き使用可(都道府県単位のみ)】

- **全国合算の件数**: 警察庁による「全国の子ども対象声かけ事案の年間認知件数」の公式統計は今回の調査では確認できなかった → **全国値は使用不可**(「全国で年間◯万件」といった表現をしない)。
- **使用可(確認済み・大阪府の例)**: 大阪府警の13歳未満の子どもに対する声かけ等事案の認知件数は**令和7年480件、令和6年516件、令和5年593件**。被害は**15時台〜17時台(下校時間帯)に集中**し、場所は**道路上が70%**、**1人でいるときの被害が47%**で最多。
- **出典名**: 大阪府警察本部「令和7年中における子供に対する声掛け等事案の認知状況(13歳未満の子供対象)」
- **出典URL**: https://www.police.pref.osaka.lg.jp/seikatsu/kodomo_jyosei/3/4145.html
- **データ年次**: 令和5年〜令和7年
- **表現例**: 「大阪府警の統計では、13歳未満の子どもへの声かけ事案は下校時間帯の15時〜17時台に集中し、7割が道路上で起きています(大阪府警察・令和7年)。」
- **参考(本文未確認のため引用時は要再確認)**: 千葉県警は令和6年中の13歳未満対象の不審者情報約1,100件を分析( https://www.police.pref.chiba.jp/seisoka/safe-life_protect-suspicious.html )、静岡県警は令和6年中の18歳以下対象の不審者情報1,250件を公表( https://www.pref.shizuoka.jp/police/kurashi/bohan/kodomo/geko/2006435.html )。

## 6. 通学路の合同点検(2021年八街市事故後の全国点検) 【使用可】

- **数値**: 2021年6月の千葉県八街市での下校中児童の列へのトラック衝突事故(児童5名死傷)を受けた全国の通学路合同点検の結果、**対策必要箇所は全国で76,404か所**(うち教育委員会・学校による対策必要箇所37,862か所)。
- **出典名**: 文部科学省「通学路における合同点検の結果について」(文科省・国交省・警察庁合同)
- **出典URL**: https://www.mext.go.jp/a_menu/kenko/anzen/1417907_00003.htm
- **データ年次**: 令和3年(2021年)実施の合同点検、令和4年(2022年)3月公表
- **表現例**: 「2021年の八街市の事故を受けて全国の通学路を合同点検した結果、対策が必要な危険箇所は7万6,404か所にのぼりました(文部科学省)。」
- **参考(進捗)**: 文科省の後続公表によると、2024年3月末時点で対策必要箇所の大半で対策済み( https://www.mext.go.jp/a_menu/kenko/anzen/1416686_00032.htm 等の続報を引用時に再確認)。

## 7. 雨天・薄暮時間帯の事故傾向

### 7a. 薄暮時間帯 【使用可】

- **数値**: 薄暮時間帯(日の入り前後1時間)の交通死亡事故(令和3年〜令和7年の5年分析)は、**17時台〜19時台に多発**。自動車対歩行者の事故が最多で、**横断中が約8割**、うち**横断歩道以外での横断が約7割**。
- **出典名**: 警察庁「薄暮時間帯における交通事故防止」
- **出典URL**: https://www.npa.go.jp/bureau/traffic/anzen/hakubo.html
- **データ年次**: 令和3年〜令和7年の5年間の分析(警察庁ページ記載)
- **表現例**: 「日没前後の『薄暮時間帯』は歩行者の死亡事故が集中する時間帯で、事故の約8割が道路横断中に起きています(警察庁)。」
- **注意**: 「薄暮の歩行者事故は昼間の約4倍」という倍率は現行の警察庁ページで確認できなかったため**使用不可**。

### 7b. 雨天 【条件付き使用可(首都高データと明記する場合のみ)】

- **数値**: 首都高速道路では、**雨天時の1時間あたり死傷事故件数は晴天時(雨天時以外)の約4倍**。
- **出典名**: 首都高速道路株式会社「雨の日に事故が多発しています」
- **出典URL**: https://www.shutoko.jp/use/safety/driver/rain/
- **データ年次**: 首都高速道路の事故統計(ページ上で年次明示なし。引用時は「首都高速道路調べ」と明記)
- **表現例**: 「首都高速道路の統計では、雨の日の死傷事故は晴れの日の約4倍に増えます(首都高速道路調べ)。」
- **注意**: 高速道路上のドライバー視点のデータであり、**通学路・子どもの歩行中事故のデータではない**。「雨の日は通学路の事故が4倍」という書き方は不可。

## 8. 小1の歩行中死傷者数と小6の比較 【倍率表現は使用不可 / 人数表現は使用可】

- **確認できた事実(使用可)**: 令和7年版交通安全白書(令和2年〜令和6年合計)で、歩行中の死者・重傷者は小学1年生446人・2年生453人と低学年に集中し、学年が上がるにつれて減少(小6の歩行中の人数は同白書の本文に明示なし)。
- **倍率(使用不可)**: 政府広報オンラインに「小学1年生の歩行中の死者・重傷者は6年生の約2.5倍/約2.9倍」という記事が存在することは確認できたが、ページ本文へのアクセスが拒否され(HTTP 403)、倍率の根拠年次を確認できなかった。**版によって倍率が異なる(約2.5倍/約2.9倍)ため、具体的な倍率は使用不可**。
  - 参考URL: https://www.gov-online.go.jp/article/201804/entry-8077.html (約2.5倍) / https://www.gov-online.go.jp/useful/article/201804/1.html (約2.9倍)
- **代替の表現例(使用可)**: 「歩行中の死者・重傷者は小学1年生が最も多い水準で(2020〜2024年合計446人)、高学年に比べて低学年のリスクが際立ちます(令和7年版交通安全白書)。」

## 使用不可まとめ(曖昧なまま記事に書かないこと)

| 項目 | 理由 |
|---|---|
| 「7歳の死傷者は成人の2.5倍・高齢者の2倍」 | ITARDA一次資料(画像PDF)で直接確認できず |
| 「小1の歩行中死者・重傷者は小6の約◯倍」(具体倍率) | 政府広報オンライン本文にアクセス不可・版により倍率が異なる |
| 「子どもへの声かけ事案は全国で年間◯件」 | 警察庁の全国合算統計を確認できず(都道府県単位の数値のみ使用可) |
| 「薄暮の歩行者事故は昼間の約4倍」 | 現行の警察庁ページに記載なし(保険会社等の二次情報のみ) |
| 「雨の日は(一般道・通学路で)事故が4倍」 | 4倍は首都高速道路限定のデータ。首都高と明記しない引用は不可 |
