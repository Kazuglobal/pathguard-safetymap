## プロダクト事実(実装済み機能のみ。出典: lib/lp-content.ts / docs/PRODUCT_OVERVIEW.md)

- **名称**: PathGuardian(パスガーディアン)
- **一言**: 通学路の危険を見える化する、家族の見守りアプリ(Webアプリ。**ブラウザで動く・インストール不要・無料・メール登録のみ**)
- **ヒーローコピー**: 「いってらっしゃい」に、確かな安心を。
- **課題設定**: 親は見送ったあとの通学路を見られない =「見えない・聞けない・間に合わない」
  - 見えない: ヒヤリとする場所は普通の地図に載っていない
  - 聞けない: 「今日どうだった?」では通学路の話は出てこない(本人も危険に気づいていない)
  - 間に合わない: 不審者・事故の情報は回覧板やニュースでは何日も遅れる

### 機能一覧(この通りにのみ記述してよい)

1. **危険マップ** — 地域のヒヤリハット報告が地図上のピンになる。近い報告はクラスタ表示され、危険が集中する場所が分かる
2. **事故ヒートマップ** — **警察庁の交通事故オープンデータ約153万件(2018〜2024年)**を地図に重ねる。子ども関与・歩行者関与のフィルタ、地点ごとの事故リスクスコアあり
   - ⚠️ 年次は必ず **2018〜2024年**と書く(旧版の「2019〜2023年」は誤り)。件数は「約153万件」。
3. **ハザードマップ** — 国土交通省のハザードマップを重ね、洪水・津波の浸水想定を通学路とあわせて確認
4. **みんなのヒヤリハット報告** — 場所を選んで3ステップで投稿。**AIと運営の二重審査**を経た情報だけが公開される
5. **不審者アラート** — 声かけ・不審者情報をプッシュ通知。通知から地図で場所を確認できる
6. **通学路の安全ニュース** — 全国の通学路に関する事故・防犯・制度のニュースを毎日選定。「今日、家族で何を話すか」の話題つき
7. **きけんハンター(目玉)** — 通学路の写真をアップすると、AIが危険箇所と安全設備を検出して写真の上に色分け描画(安全設備=緑、危険=赤)。**安全スコア**を算出。劣化したブロック塀のような見落としがちな危険も検出。子ども向け「たんけんノート」デザイン(紙質感・手書き風)、AI相棒のキャラクター**「ルペ」**
8. **通学路管理** — 家族で通学路を登録・管理。地図は登録ルート中心に表示
9. **危険箇所レポートのPDF出力** — 星による危険度表示つきの教育版デザイン。学校・PTAへの提出資料がスマホだけで作れる
10. **家族共有カード** — 危険報告の要点だけを1枚のカードにして家族へ共有(Web Share/ダウンロード)
11. **ミッション・バッジ・リーダーボード** — 子どもの継続を支えるゲーミフィケーション
12. **ホーム画面に追加(PWA)** — ブラウザで使えるうえ、ホーム画面に追加すればアプリのように起動できる。iPhone のプッシュ通知は「ホーム画面に追加した状態」でのみ届くため、アプリ内で追加手順を案内している(出典: `app/manifest.ts` / `lib/pwa-install.ts` / `components/pwa/`)
    - ⚠️ 「インストール不要」は引き続き正しい(ブラウザだけで全機能が使える)。PWA 追加は**任意**であり、必須と書かないこと

### 安全設計(信頼の根拠として書いてよい)

- 投稿はAI審査+運営確認の二重審査後に公開。個人が特定できる情報・不適切な内容は公開されない
- 顔・ナンバープレートが写る投稿は非公開に。位置情報は報告地点の共有のためだけに使う
- 危険度表示は色覚多様性・モノクロ印刷にも配慮した星表示

### 開発の文脈(開発記事で使ってよい事実)

- **個人開発**。技術: Next.js(App Router)+ React + Mapbox GL + Supabase。AI審査はサーバ側のLLM/Vision
- 153万件の事故データを地図で高速に扱うための工夫(空間集計・パフォーマンス改善)を経ている
- 子ども向けUI「たんけんノート」デザイン(Zen Maru Gothic・紙質感・キャラクター「ルペ」)を全面採用
- **柏の葉スマートシティでの実証を「目指している」段階**(実証済みではない。断定禁止)
- ブランド資産: ①子ども目線(115cm)の世界 ②153万件の実データ ③危険探しを「怒られて覚える」から「見つけて楽しい」に変える設計思想

## note向けスタイルガイド

- **語り手**: 個人開発者の一人称「私」。子を持つ読者への敬意と誠実さ。売り込み臭を出さない
- **タイトル**: 20〜35字。数字・固有名詞・ギャップ・ベネフィットのいずれかを含む。釣りすぎない
- **導入**: 最初の3〜4行で「誰のための何の話か」+フック(noteはここがタイムラインのカードに表示される)
- **構成**: `##` 見出しで3〜6セクション。1段落は2〜4文。スマホで読みやすい改行
- **分量**: 2,000〜3,500字(ハウツー系はチェックリスト付きで+500字可)
- **結び**(この順で):
  1. 短いまとめ(3行以内)
  2. 読者への行動提案(親子でできること・今日からできること)
  3. 控えめなプロダクト導線: 「通学路の安全アプリ PathGuardianをWebで無料公開しています → ▶ https://〔LPのURL〕」(URLは公開時に差し替えるプレースホルダのまま残す)
  4. 「スキ・フォローが今後の開発の励みになります」程度の一言
- **ハッシュタグ**: 記事末尾に5〜7個(例: #子育て #通学路 #小1の壁 #交通安全 #個人開発 #AI #防犯 #PTA から記事に合うもの+記事固有1〜2個)
